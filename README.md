- HTML5

- Bootstrap Icons 1.11.3

- Responsive Design
- Modern UI
- Bootstrap Components
- Bootstrap Icons
- CSS Animations and Gradients
- Mobile-Friendly Layout

## Purpose

This project was created to practice and improve frontend web development, responsive design, CSS, Bootstrap skills.
